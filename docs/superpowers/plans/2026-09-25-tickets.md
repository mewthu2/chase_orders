# Sistema de Chamados (Tickets) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sistema de chamados com responsabilidades (responsáveis fixos + prazo por vez), interações que mudam status, prints anexados (Bucketeer), acompanhantes e e-mails bonitos via Mailtrap Sandbox.

**Architecture:** Models finos (`TicketResponsability`, `Ticket`, `TicketParticipant`, `TicketMessage`) com a regra de negócio em três serviços (`Tickets::Create`, `Tickets::AddMessage`, `Tickets::AddFollower`). Todo e-mail passa por `TicketNotifier` → `TicketMailer` parametrizado com `deliver_later` (Sidekiq). Atraso detectado por `TicketOverdueJob`, disparado por rake no Heroku Scheduler.

**Tech Stack:** Rails 7.2, MySQL, Sidekiq, Devise, Active Storage (serviço `bucketeer`), ActionMailer, Minitest, WebMock, SCSS (tema escuro de `admin/_variables.scss`), JS inline vanilla.

**Spec:** `docs/superpowers/specs/2026-09-25-tickets-design.md`

## Global Constraints

- **Nunca rodar `db:migrate`/`db:seed` no banco de dev** — ele é o banco de produção. Só gerar a migration e validar no MySQL temporário (ver abaixo).
- **Nunca rodar `git commit`.** Os passos "Stage" apenas fazem `git add`.
- Trabalhar direto na `master`, sem worktree.
- Grafia dos nomes: `TicketResponsability`, `ticket_responsabilities`, `TicketResponsabilityUser`.
- Textos de interface e e-mail em pt-BR.
- Status do chamado: `awaiting_responsible`(0), `awaiting_requester`(1), `in_progress`(2), `resolved`(3), `closed`(4). Abertos = 0,1,2.
- Enum de `TicketMessage#kind`: `comment`(0), `event`(1) (nunca `system`).
- Anexos: png, jpeg, gif, webp, pdf; máx. 10 MB por arquivo; máx. 10 arquivos por envio.
- "Vence em breve" = menos de 2 horas.
- Remetente: `ENV.fetch('MAILER_FROM', 'chamados@chaseorders.com')`. Assunto sempre prefixado com `[Chamado #<id>]`.
- Destinatário de e-mail só se `active?`, `ticket_notifications_enabled?` e e-mail presente.
- Time zone da app: `Brasilia`.

## Review Focus

1. Admin que não participa abre um chamado e interage → precisa conseguir e passa a ser acompanhante (Task 4 e Task 7).
2. Upload de `.exe` ou de arquivo acima de 10 MB → erro visível, nada é salvo, nenhum e-mail enviado (Task 1 e Task 7).
3. Usuário com notificação desligada ou inativo → nunca recebe e-mail, em nenhum evento (Task 3).
4. Solicitante que também é responsável da área → um único participante, um único e-mail (Task 4).
5. Editar responsabilidade com dados inválidos → não pode apagar os responsáveis já gravados (Task 6).

```ruby
# Prints e PDFs anexados na abertura do chamado e nas interações (Active Storage → Bucketeer).
module HasTicketAttachments
  extend ActiveSupport::Concern

  ALLOWED_CONTENT_TYPES = %w[image/png image/jpeg image/gif image/webp application/pdf].freeze
  MAX_FILE_SIZE = 10.megabytes
  MAX_FILES = 10

  included do
    has_many_attached :attachments
    validate :attachments_are_acceptable
  end

  private

  def attachments_are_acceptable
    return unless attachments.attached?

    errors.add(:attachments, "no máximo #{MAX_FILES} arquivos por envio") if attachments.size > MAX_FILES
    attachments.each do |file|
      unless ALLOWED_CONTENT_TYPES.include?(file.blob.content_type)
        errors.add(:attachments, "#{file.filename}: tipo não permitido (use PNG, JPG, GIF, WEBP ou PDF)")
      end
      errors.add(:attachments, "#{file.filename}: maior que 10 MB") if file.blob.byte_size > MAX_FILE_SIZE
    end
  end
end
```

```ruby
# Área que recebe chamados: tem responsáveis fixos e o prazo (em horas corridas) que cada
# lado tem para responder a cada interação.
class TicketResponsability < ApplicationRecord
  # declarado antes das associações com dependent: :destroy — o restrict precisa rodar primeiro
  has_many :tickets, dependent: :restrict_with_error
  has_many :ticket_responsability_users, dependent: :destroy
  has_many :users, through: :ticket_responsability_users

  validates :name, presence: true, uniqueness: true
  validates :response_time_hours, numericality: { only_integer: true, greater_than: 0 }
  validate :must_have_an_active_responsible

  scope :active, -> { where(active: true) }
  scope :ordered, -> { order(:name) }

  def response_time_label
    hours = response_time_hours.to_i
    return "#{hours}h" if hours < 24 || (hours % 24).nonzero?

    days = hours / 24
    days == 1 ? '1 dia' : "#{days} dias"
  end

  private

  def must_have_an_active_responsible
    errors.add(:users, 'deve ter pelo menos um responsável ativo') unless users.any?(&:active?)
  end
end
```

```ruby
# Chamado aberto por um usuário para uma responsabilidade. O prazo (due_at) vale para quem
# está com a vez e é recalculado a cada interação — ver Tickets::AddMessage.
class Ticket < ApplicationRecord
  include HasTicketAttachments

  OPEN_STATUSES = %w[awaiting_responsible awaiting_requester in_progress].freeze
  STATUS_LABELS = {
    'awaiting_responsible' => 'Aguardando responsável',
    'awaiting_requester' => 'Aguardando solicitante',
    'in_progress' => 'Em andamento',
    'resolved' => 'Resolvido',
    'closed' => 'Fechado'
  }.freeze
  DUE_SOON_WINDOW = 2.hours

  enum :status, { awaiting_responsible: 0, awaiting_requester: 1, in_progress: 2, resolved: 3, closed: 4 }

  belongs_to :ticket_responsability
  belongs_to :requester, class_name: 'User'
  has_many :participants, class_name: 'TicketParticipant', dependent: :destroy
  has_many :users, through: :participants
  has_many :messages, -> { order(:created_at, :id) }, class_name: 'TicketMessage', dependent: :destroy

  validates :title, presence: true, length: { maximum: 150 }
  validates :description, presence: true
  validate :responsability_must_be_active, on: :create

  scope :open_tickets, -> { where(status: OPEN_STATUSES) }
  scope :overdue, -> { open_tickets.where('tickets.due_at < ?', Time.current) }
  scope :pending_overdue_notification, -> { overdue.where(overdue_notified_at: nil) }
  scope :recent_activity, -> { order(Arel.sql('COALESCE(tickets.last_activity_at, tickets.created_at) DESC'), id: :desc) }
  scope :involving, ->(user) { where(id: TicketParticipant.where(user_id: user.id).select(:ticket_id)) }

  def self.status_label(status) = STATUS_LABELS[status.to_s]

  def status_label = STATUS_LABELS[status]
  def open? = OPEN_STATUSES.include?(status)
  def overdue? = open? && due_at.present? && due_at < Time.current
  def due_soon? = open? && due_at.present? && !overdue? && due_at < DUE_SOON_WINDOW.from_now
  def response_time = ticket_responsability.response_time_hours.hours

  def participant_for(user) = participants.find { |participant| participant.user_id == user.id }
  def role_of(user) = participant_for(user)&.role
  def participant?(user) = participant_for(user).present?
  def visible_to?(user) = user.admin? || participant?(user)
  def requester?(user) = requester_id == user.id

  def responsibles = participants.select(&:responsible?).map(&:user)
  def followers = participants.select(&:follower?).map(&:user)

  # Quem precisa responder agora.
  def waiting_on_users
    return [] unless open?

    awaiting_requester? ? [requester] : responsibles
  end

  def waiting_on?(user) = waiting_on_users.include?(user)

  def waiting_on_label
    return unless open?

    awaiting_requester? ? 'Solicitante' : 'Responsáveis'
  end

  def can_resolve?(user) = user.admin? || %w[responsible follower].include?(role_of(user))
  def can_close_or_reopen?(user) = user.admin? || requester?(user)

  # Status que o usuário pode escolher ao interagir.
  def allowed_statuses_for(user)
    if open?
      statuses = OPEN_STATUSES - [status]
      statuses << 'resolved' if can_resolve?(user)
      statuses << 'closed' if can_close_or_reopen?(user)
      statuses
    elsif can_close_or_reopen?(user)
      resolved? ? OPEN_STATUSES + ['closed'] : OPEN_STATUSES.dup
    else
      []
    end
  end

  private

  def responsability_must_be_active
    return if ticket_responsability.nil? || ticket_responsability.active?

    errors.add(:ticket_responsability, 'está inativa')
  end
end
```

```ruby
# E-mails de produção pelo add-on Mailtrap da Heroku (Email Sandbox). O add-on só expõe
# MAILTRAP_API_TOKEN; as credenciais SMTP vêm da API do Mailtrap (primeira inbox).
# Atenção: é um sandbox — os e-mails ficam na inbox do Mailtrap e não chegam aos usuários.
require 'rest-client'
require 'json'

module MailtrapSandbox
  INBOXES_URL = 'https://mailtrap.io/api/v1/inboxes.json'.freeze

  def self.smtp_settings(token)
    response = RestClient.get(INBOXES_URL, { Authorization: "Bearer #{token}" })
    inbox = JSON.parse(response.body).first
    raise 'nenhuma inbox encontrada no Mailtrap' unless inbox

    {
      user_name: inbox['username'],
      password: inbox['password'],
      address: inbox['domain'],
      domain: inbox['domain'],
      port: inbox['smtp_ports'].first,
      authentication: :plain
    }
  end
end

if Rails.env.production?
  ActiveSupport.on_load(:action_mailer) do
    self.default_url_options = { host: ENV.fetch('APP_HOST', 'localhost'), protocol: 'https' }

    token = ENV['MAILTRAP_API_TOKEN']
    if token.present?
      begin
        self.delivery_method = :smtp
        self.smtp_settings = MailtrapSandbox.smtp_settings(token)
      rescue StandardError => e
        Rails.logger.error("[Mailtrap] não foi possível configurar o SMTP: #{e.class}: #{e.message}")
      end
    end
  end
end
```

```ruby
module TicketsHelper
  STATUS_COLORS = {
    'awaiting_responsible' => '#d29922',
    'awaiting_requester' => '#1f6feb',
    'in_progress' => '#8957e5',
    'resolved' => '#238636',
    'closed' => '#6e7681'
  }.freeze
  OVERDUE_COLOR = '#da3633'

  def self.status_color(status) = STATUS_COLORS.fetch(status.to_s, '#6e7681')

  def ticket_status_color(status) = TicketsHelper.status_color(status)

  def ticket_status_badge(ticket_or_status)
    status = ticket_or_status.is_a?(Ticket) ? ticket_or_status.status : ticket_or_status.to_s
    content_tag(:span, Ticket.status_label(status), class: "ticket-status ticket-status--#{status}")
  end

  def ticket_datetime(time) = time.in_time_zone.strftime('%d/%m/%Y às %H:%M')

  # "45 min", "3h", "5h20", "2 dias"
  def ticket_duration_words(seconds)
    minutes = (seconds.abs / 60).round
    return "#{minutes} min" if minutes < 60

    hours = minutes / 60
    return "#{hours / 24} dias" if hours >= 48

    rest = minutes % 60
    rest.zero? ? "#{hours}h" : format('%dh%02d', hours, rest)
  end

  def ticket_due_text(ticket)
    return 'Sem prazo (chamado encerrado)' unless ticket.open? && ticket.due_at

    remaining = ticket.due_at - Time.current
    words = ticket_duration_words(remaining)
    suffix = remaining.negative? ? "vencido há #{words}" : "em #{words}"
    "#{ticket_datetime(ticket.due_at)} (#{suffix})"
  end

  def ticket_due_class(ticket)
    return 'ticket-due--overdue' if ticket.overdue?
    return 'ticket-due--soon' if ticket.due_soon?

    ''
  end
end
```

```ruby
# E-mails do sistema de chamados. Sempre parametrizado com o chamado e o destinatário,
# para personalizar o texto conforme o papel da pessoa (solicitante, responsável, acompanhante).
class TicketMailer < ApplicationMailer
  layout 'ticket_mailer'
  helper TicketsHelper

  LOGO_PATH = Rails.root.join('app/assets/images/admin/chase-logo.png')

  before_action :load_context

  def opened
    @banner_color = TicketsHelper.status_color(@ticket.status)
    @banner_text = 'Novo chamado aberto'
    deliver_with(subject: "Novo: #{@ticket.title}")
  end

  def new_message
    @message = params[:message]
    @author = @message.user
    @recent = @ticket.messages.where.not(id: @message.id).includes(:user).last(3)
    status = @message.status_to_name
    @banner_color = TicketsHelper.status_color(status || @ticket.status)
    @banner_text = status ? "Status alterado para #{Ticket.status_label(status)}" : "Nova interação de #{@author&.name}"
    subject = status.in?(%w[resolved closed]) ? "#{Ticket.status_label(status)}: #{@ticket.title}" : "Nova interação de #{@author&.name}"
    deliver_with(subject: subject)
  end

  def follower_added
    @added_by = params[:added_by]
    @banner_color = TicketsHelper.status_color(@ticket.status)
    @banner_text = 'Você foi chamado para acompanhar um chamado'
    deliver_with(subject: "Você foi chamado para acompanhar: #{@ticket.title}")
  end

  def overdue
    @banner_color = TicketsHelper::OVERDUE_COLOR
    @banner_text = 'Prazo de resposta vencido'
    deliver_with(subject: "⚠ Prazo vencido: #{@ticket.title}")
  end

  private

  def load_context
    @ticket = params[:ticket]
    @recipient = params[:recipient]
    @role_label = (TicketParticipant::ROLE_LABELS[@ticket.role_of(@recipient)] || 'participante').downcase
    attachments.inline['chase-logo.png'] = File.binread(LOGO_PATH)
  end

  def deliver_with(subject:)
    mail(to: @recipient.email, subject: "[Chamado ##{@ticket.id}] #{subject}")
  end
end
```

```ruby
# Decide quem recebe cada e-mail de chamado. Só notifica quem está ativo, com e-mail e com
# as notificações de chamado ligadas (o admin desliga na edição do usuário).
class TicketNotifier
  def self.ticket_opened(ticket)
    recipients(ticket).each { |user| deliver(:opened, ticket: ticket, recipient: user) }
  end

  def self.message_created(message)
    ticket = message.ticket
    recipients(ticket, except: message.user).each do |user|
      deliver(:new_message, ticket: ticket, recipient: user, message: message)
    end
  end

  def self.follower_added(ticket, follower, added_by:)
    return unless follower.ticket_notifications?

    deliver(:follower_added, ticket: ticket, recipient: follower, added_by: added_by)
  end

  # Avisa quem está com a vez; se a vez é dos responsáveis, o solicitante também fica sabendo.
  def self.overdue(ticket)
    users = ticket.waiting_on_users
    users += [ticket.requester] unless ticket.awaiting_requester?
    users.uniq.select(&:ticket_notifications?).each { |user| deliver(:overdue, ticket: ticket, recipient: user) }
  end

  def self.recipients(ticket, except: nil)
    TicketParticipant.where(ticket: ticket).includes(:user).map(&:user).uniq
                     .reject { |user| user == except }
                     .select(&:ticket_notifications?)
  end
  private_class_method :recipients

  def self.deliver(action, **params)
    TicketMailer.with(**params).public_send(action).deliver_later
  end
  private_class_method :deliver
end
```

```ruby
module Tickets
  # Abre um chamado: copia os responsáveis da responsabilidade para o chamado (snapshot —
  # mudar a responsabilidade depois não mexe em chamados antigos), inclui os acompanhantes
  # escolhidos, calcula o prazo da primeira resposta e notifica todos.
  class Create
    def self.call(...) = new(...).call

    def initialize(requester:, attributes:, follower_ids: [])
      @requester = requester
      @attributes = attributes
      @follower_ids = Array(follower_ids).reject(&:blank?).map(&:to_i)
    end

    def call
      now = Time.current
      ticket = Ticket.new(@attributes)
      ticket.assign_attributes(requester: @requester, status: :awaiting_responsible, last_activity_at: now)
      ticket.due_at = now + ticket.response_time if ticket.ticket_responsability
      build_participants(ticket)
      return ticket unless ticket.save

      TicketNotifier.ticket_opened(ticket)
      ticket
    end

    private

    def build_participants(ticket)
      ticket.participants.build(user: @requester, role: :requester)

      responsibles = ticket.ticket_responsability&.users.to_a.select(&:active?) - [@requester]
      responsibles.each { |user| ticket.participants.build(user: user, role: :responsible) }

      taken = [@requester.id] + responsibles.map(&:id)
      User.active.where(id: @follower_ids - taken).find_each do |user|
        ticket.participants.build(user: user, role: :follower)
      end
    end
  end
end
```

```ruby
module Tickets
  # Registra uma interação e aplica a regra de status/prazo:
  # - sem status escolhido, a vez passa para o outro lado (solicitante ⇄ responsáveis) e o
  #   prazo recomeça; em chamado resolvido/fechado vira só um comentário;
  # - status escolhido precisa estar em ticket.allowed_statuses_for(author);
  # - "resolved" exige o texto da solução, que fica guardado no chamado.
  # Admin que não participa e interage entra como acompanhante.
  class AddMessage
    def self.call(...) = new(...).call

    def initialize(ticket:, author:, body: nil, status: nil, attachments: [])
      @ticket = ticket
      @author = author
      @body = body.to_s.strip.presence
      @status = status.presence
      @attachments = Array(attachments).reject(&:blank?)
    end

    def call
      @message = TicketMessage.new(ticket: @ticket, user: @author, kind: :comment, body: @body, attachments: @attachments)
      @message.status_to = Ticket.statuses[@status] if @status
      return @message unless permitted? && @message.valid?

      @message.status_from = Ticket.statuses[@ticket.status] if @status
      apply_transition(Time.current)

      Ticket.transaction do
        ensure_participant
        @message.save!
        @ticket.save!
      end
      TicketNotifier.message_created(@message)
      @message
    end

    private

    def permitted?
      unless @ticket.visible_to?(@author)
        @message.errors.add(:base, 'Você não participa deste chamado')
        return false
      end
      return true unless @status

      unless @ticket.allowed_statuses_for(@author).include?(@status)
        @message.errors.add(:base, 'Você não pode mudar o chamado para esse status')
        return false
      end
      if @status == 'resolved' && @body.blank?
        @message.errors.add(:base, 'Descreva a solução para marcar como resolvido')
        return false
      end
      true
    end

    def apply_transition(now)
      @ticket.last_activity_at = now
      @ticket.overdue_notified_at = nil
      target = @status || automatic_status
      return unless target

      @ticket.status = target
      case target
      when 'resolved'
        @ticket.assign_attributes(solution: @body, resolved_at: now, closed_at: nil, due_at: nil)
      when 'closed'
        @ticket.assign_attributes(closed_at: now, due_at: nil)
      else
        @ticket.assign_attributes(resolved_at: nil, closed_at: nil, due_at: now + @ticket.response_time)
      end
    end

    def automatic_status
      return unless @ticket.open?

      @ticket.requester?(@author) ? 'awaiting_responsible' : 'awaiting_requester'
    end

    def ensure_participant
      return if @ticket.participant?(@author)

      @ticket.participants.create!(user: @author, role: :follower)
    end
  end
end
```

```ruby
module Tickets
  # Chama outra pessoa para acompanhar o chamado: vira participante (follower), fica
  # registrado na timeline e só ela recebe e-mail.
  class AddFollower
    Result = Data.define(:success, :error) do
      def success? = success
    end

    def self.call(...) = new(...).call

    def initialize(ticket:, user:, added_by:)
      @ticket = ticket
      @user = user
      @added_by = added_by
    end

    def call
      return failure('Você não participa deste chamado') unless @ticket.visible_to?(@added_by)
      return failure('Usuário inválido ou inativo') unless @user&.active?
      return failure("#{@user.name} já participa deste chamado") if @ticket.participant?(@user)

      Ticket.transaction do
        @ticket.participants.create!(user: @user, role: :follower)
        @ticket.messages.create!(kind: :event, body: "#{@added_by.name} chamou #{@user.name} para acompanhar o chamado")
        @ticket.update!(last_activity_at: Time.current)
      end
      TicketNotifier.follower_added(@ticket, @user, added_by: @added_by)
      Result.new(success: true, error: nil)
```

```ruby
# Avisa por e-mail os chamados que passaram do prazo de resposta. Cada vencimento gera um
# único aviso: overdue_notified_at é zerado quando alguém interage (Tickets::AddMessage).
# Agendado pelo Heroku Scheduler via `rake tickets:notify_overdue` (a cada 10 minutos).
class TicketOverdueJob < ApplicationJob
  queue_as :default

  def perform
    Ticket.pending_overdue_notification.includes(:requester, participants: :user).find_each do |ticket|
      TicketNotifier.overdue(ticket)
      ticket.update_columns(overdue_notified_at: Time.current)
    end
  end
end
```

```ruby
class HomeController < ApplicationController
  before_action :authenticate_user!

  # Painel de chamados: cada um vê os chamados em que participa; admin pode ver todos.
  def index
    @scope_all = current_user.admin? && params[:scope] == 'all'
    base = @scope_all ? Ticket.all : Ticket.involving(current_user)
    @status_filter = params[:status].presence || 'open'

    @counters = {
      waiting_me: waiting_on_me(base).count,
      waiting_others: base.open_tickets.count - waiting_on_me(base).count,
      overdue: base.overdue.count,
      resolved_week: base.where('tickets.resolved_at >= ?', 7.days.ago).count
    }

    tickets = filter_by_status(base, @status_filter)
    tickets = tickets.where(ticket_responsability_id: params[:ticket_responsability_id]) if params[:ticket_responsability_id].present?
    if TicketParticipant.roles.key?(params[:role])
      tickets = tickets.where(id: TicketParticipant.where(user_id: current_user.id, role: params[:role]).select(:ticket_id))
    end

    @tickets = tickets.includes(:ticket_responsability, :requester, participants: :user)
                      .recent_activity.paginate(page: params[:page], per_page: 20)
    @responsabilities = TicketResponsability.ordered
  end

  private

  def filter_by_status(scope, filter)
    case filter
    when 'open' then scope.open_tickets
    when 'waiting_me' then scope.where(id: waiting_on_me(scope).select(:id))
    when 'overdue' then scope.overdue
    when *Ticket.statuses.keys then scope.where(status: filter)
    else scope
    end
  end

  # Abertos em que a vez é minha: sou o solicitante e ele aguarda o solicitante, ou sou
  # responsável e ele aguarda os responsáveis.
  def waiting_on_me(scope)
    responsible_of = TicketParticipant.where(user_id: current_user.id, role: :responsible).select(:ticket_id)
    scope.where(status: :awaiting_requester, requester_id: current_user.id)
         .or(scope.where(status: [:awaiting_responsible, :in_progress], id: responsible_of))
  end
end
```
